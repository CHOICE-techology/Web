# CHOICE iD Identity Studio (open)

An open working folder for the CHOICE iD interactive 3D identity scene: what it is, how it was built, the models, the code, the reports and the next step. Built in public so that anyone, including outside reviewers and AI tools, can follow the work from the files alone.

Start here, in this order:
1. `STATUS.md`: where we are now and what waits for a decision.
2. `NEXT-STEP.md`: the proposed next step and the prompt for it.
3. `HISTORY.md`: how we got here.
4. `MODELS.md`: every 3D object, its size, and where it is.
5. `docs/`: every handover, spec and report, unedited.
6. `images/` and `video/`: the evidence (Cycles master, browser comparisons, 7 s film).
7. `source/`: the prototype code and the tools that made the images.
8. `models/`: the GLB files.

Rules that hold: brand book (Oct 2026) is authoritative; no pink; cyan #34FAFB only as a signal; no check marks, scores or rankings; no invented product UI; stop at each gate for approval. This folder is not the live website and changes nothing on it.
